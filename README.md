# vps-tool

一个面向 **Debian** 和 **Alpine Linux** VPS 的 Bash 综合管理工具，集中管理 SSH 安全、Fail2Ban 和常用系统优化功能。

仓库地址：<https://github.com/xpeb/vps-tool>

## 功能

### SSH 与密钥管理

- 从 GitHub 或自定义 HTTPS 地址获取公钥
- 在 VPS 上生成 ED25519 密钥对
- 查看、删除和清空 `authorized_keys` 中的公钥
- 开关密钥登录和密码登录
- 修改 SSH 端口
- 修改前自动备份 SSH 配置，语法检查失败时尝试回滚
- 修改 SSH 端口时同步检查 UFW、firewalld 和 SELinux 端口规则

### Fail2Ban 防护

- 安装、启动、停止和卸载 Fail2Ban
- 管理 SSH 最大重试次数、封禁时间和检测时间窗口
- 管理封禁 IP、解封 IP 和白名单
- 查看封禁与解封日志
- 配置递增封禁时间
- 自动同步当前 SSH 端口
- 修改配置前进行备份和配置测试

### 系统优化

- 配置 BBR + FQ
- 配置 zRAM
- 设置 `Asia/Shanghai` 时区
- 清理包管理器缓存和过期日志
- 管理 Docker 和 Compose
- 查看系统、网络算法、zRAM、Docker 和时区状态

## 安装

仓库已公开，使用以下一条命令下载并启动脚本：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/xpeb/vps-tool/main/vps.sh)
```

请以 `root` 身份执行此命令。

脚本必须以 `root` 身份运行。建议先通过云厂商控制台、VNC 或其他带外管理方式确认具备恢复 VPS 的能力，再修改 SSH 配置。

## 支持环境

- Debian
- Alpine Linux
- Debian 通常使用 `apt`
- Alpine 通常使用 `apk`
- 支持 systemd、OpenRC，并提供有限的 SysVinit 兼容处理

脚本启动时会检查并按需安装基础依赖。不同功能还可能依赖系统中已有的 SSH 服务、防火墙、日志服务或内核模块。

## 安全注意事项

1. **修改 SSH 前保持当前会话打开**。修改端口、密码登录或密钥登录后，先用新的终端测试成功，再关闭旧会话。
2. **不要在没有可用公钥的情况下禁用密码登录**。脚本会进行风险提示，但最终操作仍需由管理员确认。
3. **私钥不会打印到终端**。在 VPS 上生成密钥后，请使用受信任的 SFTP 工具下载私钥，不要通过聊天、邮件或不受信任的终端传输。
4. **Docker 卸载会删除数据**。输入 `DELETE` 确认后，可能删除容器、镜像、卷以及 Docker 数据目录；执行前请确认备份。
5. **系统清理会删除过期日志和缓存**。如果需要审计记录，请先完成日志备份。
6. **远程获取公钥仅支持 HTTPS**。只使用自己信任的 GitHub 账号或 HTTPS 地址。

## SSH 变更建议

建议按以下顺序完成 VPS 加固：

1. 确认当前 SSH 服务正常运行
2. 添加并验证至少一个可用公钥
3. 使用新终端测试密钥登录
4. 如有需要，再修改 SSH 端口
5. 确认云安全组和系统防火墙已放行新端口
6. 最后再禁用密码登录
